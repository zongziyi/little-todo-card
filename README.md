# 小小待办 · Little Todo Card

一个运行在 Windows 桌面上的本地待办工具，包含两张可以独立移动和缩放的小卡片。

- **倒数日清单**：为待办选择截止日期，显示剩余天数；按日期排序，支持手动置顶。
- **短期待办**：无需日期，适合记录近期要做的事；按新增时间排序，也可以置顶。
- 两张卡片都支持添加、编辑、完成、恢复和删除；关闭前可以单独隐藏，并从系统托盘重新显示。
- 窗口位置、大小、显示状态与待办保存在本机，支持在设置中开启开机自启。

此项目基于 [ApexTodo](https://github.com/XGxin/ApexTodo) 修改，保留原项目的 Git 历史和 GPL-3.0 许可证。原项目作者为 BigWatermelon。界面、双卡片、倒数日和置顶功能为此版本的修改。

## 使用

1. 运行程序后，桌面会显示“我的待办”和“短期待办”两张卡片。
2. 点击右上角 **＋** 添加事项；点击事项文字可编辑，左侧方框用于完成或恢复。
3. 点击图钉置顶或取消置顶；点击 **×** 删除事项。
4. 拖动卡片顶部移动，拖动边缘调整大小。点击 **－** 隐藏卡片；右键系统托盘图标可以重新显示。
5. 点击齿轮进入设置，可启用开机自启或退出程序。

两份清单和窗口设置默认保存在当前 Windows 用户的 `%APPDATA%\LittleTodoCard` 文件夹。备份时请先退出程序，再复制该文件夹。仓库不包含使用者的实际待办数据。

桌面固定沿用原项目的 Windows 近似实现，不是系统壁纸层组件，“显示桌面”后的表现可能因 Windows 环境而异。

## 从源码运行

需要 Windows 10/11（x64）和 Node.js 22.12 或更高版本。

```powershell
npm ci
node .\node_modules\electron\install.js
npm run dev
```

Electron 的运行文件需要在联网时下载。运行测试和生成免安装目录：

```powershell
npm test
npm run dist
```

构建结果在 `release/win-unpacked/`。运行时请保留该文件夹中的全部文件，双击 `LittleTodo.exe` 打开。此项目的构建没有代码签名，也没有配置 Microsoft Store 自动更新。
